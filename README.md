# gamejam-2627-gd-fs-team-Goygar
platformer beat em up
simpele 2D platformer game, waarbij je een karakter bestuurt die tegenstanders op platforms aanvalt met t idee om ze eraf te gooien zodat je verder kan gaan, je wint als je een eindpunt bereikt
up voor springen, down voor crouchen, links en rechts om... links en rechts te gaan
A en B voor aanvallen, A is een punch, B is een kick, andere aanvallen als je croucht of midair zit
